REPRODUCIBLE METHODS - verified 21 October 2026
DATA: GSE43292, GPL6244; 64 RMA-preprocessed microarray samples from 32 hypertensive patients. Paired plaque and macroscopically intact tissue. No raw-array reprocessing or additional normalization.
MODEL: R 4.3.3, limma 3.58.1, statmod 1.5.0. Explicit patient and tissue factors from metadata; design ~ patient + tissue; plaque minus intact. lmFit followed by eBayes(robust=TRUE). BH across all 33,297 probe tests; adjusted p <0.01 and |log2FC| >1. The 147 selected probes and their numerical statistics reproduce the original output to machine precision.
ANNOTATION: retain the captured original hugene10sttranscriptcluster.db symbol mapping. Missing-symbol and duplicate-symbol removal gives 114 genes (58 higher, 56 lower). Exact original annotation package version was not recorded. Original full table contains 19,997 unique symbols; representative probes were selected by highest absolute logFC per symbol. Its saved fold changes match the rerun within 5e-8 (rounding). Enrichment uses freshly recomputed logFC for those captured representatives.
ENRICHMENT MAPPING: org.Hs.eg.db 3.18.0, Entrez source 2023-Sep11 and GO annotation source 2023-Sep11; GO.db 3.18.0. First mapping in database order per symbol; highest absolute logFC for duplicate Entrez IDs. 19,885 unique mapped Entrez IDs. Record these historical annotation snapshots rather than describe them as current annotations.
GENE SETS: GO BP including ancestor annotations from org.Hs.eg.db/go_bp_all, with terms from GO.db. KEGG human pathways retrieved from rest.kegg.jp on 21 October 2026. Frozen sets are held in the private audit bundle for personal reproducibility; this package grants no redistribution rights over third-party resources.
GSEA: fgsea 1.36.2, fgseaMultilevel, logFC-ranked Entrez vector, minSize=10, maxSize=500, eps=0, nPermSimple=1000, nproc=1; seed 43292 for each database. BH within each database. Tests: 6,310 GO BP sets and 353 KEGG pathways; significant at FDR<0.05: 1,379 and 121 respectively. 0.07% of ranking values tie; the recorded ranked CSV fixes their input order. Seed and input order are preserved. Exact stochastic estimates can depend on package version.
ORA: Python scipy hypergeom survival function, combined up/down DEGs. For each database, intersect tested mapped genes with genes annotated in that database. GO BP universe 17,012 and foreground 103; KEGG universe 8,397 and foreground 58. Test every eligible gene set of size 10-500 including zero-hit sets, then BH over all tested sets. GO BP 15 significant terms; KEGG 2 significant pathways. Independent R p.adjust checks reproduce both BH columns. This explicit all-term testing family differs from tools that omit zero-overlap terms. ORA cannot by itself establish pathway activation or direction.
NETWORK: use the saved STRING functional-association network, 47 nodes and 107 undirected edges, obtained for the original upregulated gene query at reported STRING confidence 0.4. Recompute Degree and MCC with Python networkx. MCC equals sum of (clique size - 1)! across maximal cliques containing the node. All 20 exported top-ten scores match. Nine identifiers overlap between rankings. The network was not downloaded anew, and the network and enrichment reruns use different annotation/database snapshots. MCODE results are not used in this portfolio case study.
FIGURES: volcano uses full rerun probe table; heatmap uses the top ten unique annotated significant genes by absolute logFC, gene-wise z-scores, and the uploaded expression matrix. GSEA display chooses the six smallest adjusted p-values among positive-NES GO BP sets. Network figure shows the induced subgraph of the original MCC top ten, not all 47 nodes.
INTERPRETATION: single-dataset observational reanalysis; intact tissue is not healthy-donor tissue; cell composition can influence expression and enrichment. Connectivity and agreement between methods do not validate biomarkers or causality. No patient-level diagnostic claim.
ORIGIN: personal reanalysis developed from MSc coursework. Portfolio extension included assisted code review, rerunning, statistical checks and figure preparation. R and Cytoscape were part of the supplied coursework; Python supports the verification and reporting extension. This project alone does not establish independent Python service capability.
